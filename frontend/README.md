# ASTRAL frontend

React Three Fiber app: a 3D "astral map" of Earth, the Moon and Mars. Pick a site on
the Moon or Mars and see its Earth analogs, with per-dimension scores and an honest
account of what is *not* comparable (gravity, vacuum, radiation).
