# Moon globe textures

Equirectangular (2:1), longitude -180 to 180 (left to right), north up. Generated by
`python -m ml.textures --body moon` (ASTRAL, NASA Space Apps 2026).

| File | Resolution | What it is | Source | License |
| --- | --- | --- | --- | --- |
| `color_8k.jpg`, `color_4k.jpg` | 8192x4096, 4096x2048 | True color | NASA SVS CGI Moon Kit (LRO LROC WAC color mosaic, poles filled), svs.gsfc.nasa.gov/4720 | NASA imagery: no copyright, credit NASA (see nasa.gov/nasa-brand-center/images-and-media) |
| `height_4k.png` + `height.json` | 4096x2048 | 8-bit grayscale height (min -9,065 m, max 10,654 m) for displacement | LRO LOLA GDR ldem_64 (64 px/deg) | Public domain (NASA) |
| `normal_4k.jpg` | 4096x2048 | Normal map from the same height (vertical exaggeration x8) | derived from LRO LOLA GDR ldem_64 (64 px/deg) | Public domain (NASA) |
| `hillshade_4k.jpg` | 4096x2048 | Hillshade, sun from the NW at 45 deg | derived from LRO LOLA GDR ldem_64 (64 px/deg) | Public domain (NASA) |
| `topography_4k.jpg` + `topography_legend.png` | 4096x2048 | Color topography, legend in meters | derived from LRO LOLA GDR ldem_64 (64 px/deg) | Public domain (NASA) |
| `suitability_4k.png` + `suitability_legend.png` | 8192x4096 | Base suitability 0-1 (viridis), transparent where there is no data. Moon south pole only (south of ~75 S, LOLA polar grid); 8192x4096 so the polar cap keeps detail. A suggestion, not a site selection | ml/suitability_moon.py (LOLA slope, Diviner ice and temperature) | Public domain (NASA data) |

Height decoding: `height_m = min_m + (pixel / 255) * (max_m - min_m)` (see `height.json`).
Notes: rows beyond 90 / -90 deg filled with the nearest valid row
