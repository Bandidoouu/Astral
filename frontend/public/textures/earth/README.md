# Earth globe textures

Equirectangular (2:1), longitude -180 to 180 (left to right), north up. Generated by
`python -m ml.textures --body earth` (ASTRAL, NASA Space Apps 2026).

| File | Resolution | What it is | Source | License |
| --- | --- | --- | --- | --- |
| `color_8k.jpg`, `color_4k.jpg` | 8192x4096, 4096x2048 | True color | NASA GIBS WMS, BlueMarble_NextGeneration (NASA Earth Observatory Blue Marble) | NASA imagery: no copyright, credit NASA (see nasa.gov/nasa-brand-center/images-and-media) |
| `height_4k.png` + `height.json` | 4096x2048 | 8-bit grayscale height (min -415 m, max 6,376 m) for displacement | NASA SRTMGL30 v002 (30 arc-sec) | Public domain (NASA) |
| `normal_4k.jpg` | 4096x2048 | Normal map from the same height (vertical exaggeration x20) | derived from NASA SRTMGL30 v002 (30 arc-sec) | Public domain (NASA) |
| `hillshade_4k.jpg` | 4096x2048 | Hillshade, sun from the NW at 45 deg | derived from NASA SRTMGL30 v002 (30 arc-sec) | Public domain (NASA) |
| `topography_4k.jpg` + `topography_legend.png` | 4096x2048 | Color topography, legend in meters | derived from NASA SRTMGL30 v002 (30 arc-sec) | Public domain (NASA) |

Height decoding: `height_m = min_m + (pixel / 255) * (max_m - min_m)` (see `height.json`).
Notes: ocean = 0 m (SRTMGL30); south of 60 S (Antarctica) has no SRTMGL30 data: filled with 0 m
