# Mars globe textures

Equirectangular (2:1), longitude -180 to 180 (left to right), north up. Generated by
`python -m ml.textures --body mars` (ASTRAL, NASA Space Apps 2026).

| File | Resolution | What it is | Source | License |
| --- | --- | --- | --- | --- |
| `color_8k.jpg`, `color_4k.jpg` | 8192x4096, 4096x2048 | True color | NASA Mars Trek, Mars_Viking_MDIM21_ClrMosaic_global_232m (Viking color mosaic), WMTS level 4 | NASA imagery: no copyright, credit NASA (see nasa.gov/nasa-brand-center/images-and-media) |
| `height_4k.png` + `height.json` | 4096x2048 | 8-bit grayscale height (min -8,166 m, max 21,154 m) for displacement | MGS MOLA MEGDR 128 px/deg | Public domain (NASA) |
| `normal_4k.jpg` | 4096x2048 | Normal map from the same height (vertical exaggeration x6) | derived from MGS MOLA MEGDR 128 px/deg | Public domain (NASA) |
| `hillshade_4k.jpg` | 4096x2048 | Hillshade, sun from the NW at 45 deg | derived from MGS MOLA MEGDR 128 px/deg | Public domain (NASA) |
| `topography_4k.jpg` + `topography_legend.png` | 4096x2048 | Color topography, legend in meters | derived from MGS MOLA MEGDR 128 px/deg | Public domain (NASA) |
| `suitability_4k.png` + `suitability_legend.png` | 4096x2048 | Base suitability 0-1 (viridis), transparent where there is no data. Mars 60 N to 60 S (Mars Odyssey hydrogen coverage); 0.25 deg cells. A suggestion, not a site selection | ml/suitability_mars.py (MOLA slope and elevation, Mars Odyssey GRS hydrogen) | Public domain (NASA data) |

Height decoding: `height_m = min_m + (pixel / 255) * (max_m - min_m)` (see `height.json`).
Notes: rows beyond 88 / -88 deg filled with the nearest valid row
